# PSToml

TOML parser and writer for PowerShell.

## Version

Backup-Toolkit is bundled with and tested against PSToml v0.5.0 (2026-04-02).

## Project

[PSToml on GitHub](https://github.com/jborean93/PSToml)

## Download

Download the NuGet package (`*.nupkg`) from the project and change its extension to `.zip`.
